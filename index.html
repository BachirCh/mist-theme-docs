01

Overview

Mist is an Online Store 2.0 theme: every page is a JSON template made of sections you can add, remove and reorder in the theme editor. It is built on Shopify's Skeleton theme with original code, uses no third-party scripts, and ships as plain Liquid, CSS and a single deferred JavaScript file.

  • Home: looping slideshow, product tabs, collection carousel, bundle builder, press quotes, image with text, product carousel, scrolling text, shoppable gallery, reviews and FAQ.
  • Shopping: product cards with quick add and quick view, AJAX filters and sorting, a cart drawer (or cart page) with a free-shipping bar, gift wrap and a shipping estimator.
  • Pages: product, collection, collection list, search, blog, article, page (default, about, FAQ, contact, policies), cart, password, 404 and gift card templates.
Requirements. A Shopify store with the Online Store sales channel. Product ratings need a metafield (see Product page); product recommendations need Shopify's free Search & Discovery app.

02

Install and first steps

  1. In Shopify admin go to Online Store → Themes → Add theme → Upload zip file and choose mist-1.1.0.zip.
  2. Click Customize. A fresh install shows starter content and placeholders; nothing points at products you don't own.
  3. Upload your logo under Theme settings → Logo and favicon. With no logo the store name is shown as a text logo in the font chosen under Typography → Text logo.
  4. In the Header section choose your menu (the default is main-menu). Choose your footer menus in the Footer section.
  5. On the home page click each section and pick your own collections, products and images. Sections with empty slots show placeholders until you do.
  6. Create a Gift wrap product if you want the cart's gift-wrap option, then select it under Theme settings → Cart.
  7. Check the mobile preview using the device toggle, then click Save.

03

Presets and styles

Mist ships with one preset, Mist. You change its look in Theme settings: colours, fonts, page width, spacing, corner radii and product-card options (see Global theme settings). For example, set all four radii to 0 for a sharp, editorial look, or raise the button and input radii back to 40 px for the default pill shape.

Individual sections have their own colour and spacing settings (top and bottom padding, tinted backgrounds, slide colours), so you can vary the rhythm of the page without touching global settings.

04

Header and navigation

Announcement bar

Up to 8 Message blocks, each with text and an optional link. Settings: Scroll messages (a continuous marquee, or a static row when off), Scroll duration, background and text colours. The scrolling copy is hidden from screen readers and replaced by a plain list of the same messages.

Header

SettingWhat it does
MenuThe menu shown in the header (default main-menu).
Sticky headerKeeps the header at the top while scrolling.
Full widthLets the header span the full window width instead of the page width.
Mega menu promotionImage, heading and link shown beside the columns of a mega menu.

Two-level menus open as a dropdown. Three-level menus (a link with children that have their own children) open as a mega menu with a column per second-level link. Menus open on hover, on keyboard focus, and with the Down Arrow key; Esc closes them. On touch devices the first tap opens a submenu and the second follows the link.

Icons, search and mobile

The header shows search, account (when customer accounts are on) and cart icons; the cart icon carries an item count. Search opens a panel from the top with search suggestions (products, plus prices when enabled in Theme settings → Search). On phones the menu becomes a slide-in drawer where menu items with children expand as accordions and every group has a “View all” link.

Product cards

A card is a soft rounded tile: image, optional product type or vendor, title, optional rating and price. Sale prices show the compare-at price struck through. Options live under Theme settings → Product cards.

08

Collections and search

The Product grid section shows the collection title, description, product count, sorting and filtering. Filters come from Shopify's Search & Discovery app.

  • Filtering: tick availability and other filters or set a price range. Results update without a page reload, the URL stays shareable, and removable chips show what is active. On phones (and optionally on desktop) filters open in a drawer; choose Sidebar or Drawer under Desktop filter layout.
  • Sorting: the sort options defined for the collection.
  • Grid: products per page (8 to 48), columns on desktop (2 to 5), and 1 or 2 columns on mobile. Pagination links update the grid without a full reload.
  • Empty results: a message and a “clear all” button appear when the filters match nothing.

Search results use the same product cards, with results per page, columns and filters. A page for “no results” explains what to try. Collections list lets you pick collections, sort them, choose columns and hide empty ones.

09

Cart

Choose Drawer or Page under Theme settings → Cart. In drawer mode, adding an item opens the drawer; the cart icon opens it at any time. The drawer and the cart page share these features:

  • Free-shipping progress bar: set a threshold in your store's currency; 0 hides the bar.
  • Quantity controls and remove, updated without reloading.
  • Cart page extras: order note, gift wrap (adds your chosen Gift wrap product as a line; unticking removes it), a shipping estimator (country, province and postcode) and accelerated checkout buttons.
  • Empty cart: a message with a “Continue shopping” button, plus recommendations when a fallback collection is set.

12

Localisation and RTL

Every customer-facing string is in locales/en.default.json. To translate, add languages under Settings → Languages and use Edit default theme content / Edit languages in the theme editor. The footer shows country and language selectors when your store sells in more than one.

The theme switches to right-to-left automatically for Arabic, Hebrew, Persian and Urdu. Spacing, positioning and borders use logical CSS properties, and arrow icons, carousels and drawers mirror. Text you type into a section is treated as bidirectional so mixed-language names display correctly.

13

Performance and accessibility

  • No third-party scripts or libraries; one deferred JavaScript file and one stylesheet, with fonts loaded from Shopify's font service.
  • Images use responsive srcset, lazy loading below the fold, and the first slide or product image loads eagerly with high priority.
  • Recommendations, quick view and cart updates load through Shopify's Section Rendering API, not full page loads.
  • A skip-to-content link, one h1 per page, labelled form fields, visible focus outlines, focus trapped in dialogs and returned on close, Esc to close drawers, and live regions for cart and search updates.
  • Scroll-reveal animations and marquees are switched off for visitors who prefer reduced motion.
  • Default colours meet WCAG AA contrast; check your own colour changes with a contrast checker.
